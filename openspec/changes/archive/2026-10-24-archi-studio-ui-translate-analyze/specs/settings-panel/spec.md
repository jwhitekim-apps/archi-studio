# Spec Delta

## Purpose

셸의 오른쪽 설정 패널이 현재 열린 도구(번역, 분석)가 제공한 설정만 보여주도록 하는 규칙과, 번역·분석 도구의 설정 항목, 설정을 저장하는 방식을 정의한다. 3단 레이아웃 자체는 `app-shell` 스펙이 정한다.

## ADDED Requirements

### Requirement: 도구별 설정 표시
시스템은 오른쪽 설정 패널에 현재 화면이 제공한 설정 내용을 보여줘야 한다(SHALL). 화면이 설정을 제공하지 않으면 패널은 기본 안내문("선택한 도구의 설정이 여기에 표시됩니다.")을 보여준다. 화면을 이동하면 이전 화면의 설정은 패널에서 사라진다(MUST).

#### Scenario: 번역 화면의 설정
- **WHEN** 사용자가 `/translate`를 연다
- **THEN** 오른쪽 패널의 제목은 "설정"이고 안에 번역 설정 항목이 보인다

#### Scenario: 화면 이동
- **WHEN** 번역 화면에서 분석 화면으로 이동한다
- **THEN** 패널에서 번역 설정이 사라지고 분석 설정이 보인다

#### Scenario: 설정이 없는 화면
- **WHEN** 설정을 제공하지 않는 화면을 연다
- **THEN** 패널에는 기본 안내문이 보이고 이전 화면의 설정은 남지 않는다

### Requirement: 번역 설정 항목
시스템은 번역 화면의 설정 패널에 세 항목을 제공해야 한다(SHALL). 첫째, "자동 번역"은 켜면 입력이 멈춘 뒤 0.3초 후 자동으로 번역을 실행하고 기본은 꺼짐이다. 둘째, 논문이 연결되어 있으면 연결된 논문의 제목과 "연결 해제" 버튼을 보여주고, 연결이 없으면 이 항목은 숨긴다. 셋째, 논문이 연결되어 있을 때만 "이력 범위"(전체 / 이 논문만)를 보여준다.

#### Scenario: 자동 번역 기본값
- **WHEN** 처음 방문한 사용자가 번역 화면을 연다
- **THEN** "자동 번역"은 꺼져 있고, 입력해도 번역 버튼을 누르기 전에는 요청이 보내지지 않는다

#### Scenario: 자동 번역 켜기
- **WHEN** "자동 번역"을 켜고 문장을 입력한 뒤 0.3초 동안 입력을 멈춘다
- **THEN** 번역 요청이 한 번 보내진다
- **AND** 입력을 계속하면 이전 요청은 취소된다

#### Scenario: 연결 해제
- **WHEN** 논문이 연결된 화면에서 "연결 해제"를 누른다
- **THEN** 화면 주소에서 `paperId`가 사라지고 이후 번역 요청에는 `paperId`가 없으며, 연결 논문 항목과 "이력 범위" 항목이 패널에서 사라진다

### Requirement: 분석 설정 항목
시스템은 분석 화면의 설정 패널에 두 항목을 제공해야 한다(SHALL). 첫째, "대상 논문"은 현재 논문의 제목을 보여주고 "변경" 버튼으로 논문 선택기로 돌아간다. 둘째, "저장된 결과 다시 불러오기"는 `GET /api/papers/{id}/analysis`를 다시 호출하고, AI를 호출하는 분석은 시작하지 않는다.

#### Scenario: 대상 논문 변경
- **WHEN** 분석 화면의 설정 패널에서 "변경"을 누른다
- **THEN** `paperId` 없는 `/analyze` 논문 선택기 화면이 열린다

#### Scenario: 다시 불러오기
- **WHEN** "저장된 결과 다시 불러오기"를 누른다
- **THEN** 저장된 분석 조회가 한 번 다시 보내지고 `POST /api/papers/{id}/analysis`는 보내지지 않는다

### Requirement: 설정 저장
시스템은 "자동 번역" 선택을 사용자의 브라우저에 저장해 다음 방문에도 유지해야 한다(SHALL). 서버에는 설정을 저장하지 않는다. 브라우저 저장소를 쓸 수 없는 환경에서는 기본값으로 동작하고 오류를 보여주지 않는다(MUST).

#### Scenario: 다음 방문에도 유지
- **WHEN** "자동 번역"을 켜고 페이지를 새로고침한다
- **THEN** 번역 화면의 "자동 번역"은 켜진 상태다

#### Scenario: 브라우저 저장소 사용 불가
- **WHEN** 브라우저 저장소 접근이 막힌 환경에서 번역 화면을 연다
- **THEN** "자동 번역"은 기본값(꺼짐)이고 화면에 오류가 표시되지 않는다

### Requirement: 좁은 화면과 접근성
시스템은 폭 768px 미만에서 설정 패널을 `app-shell` 스펙의 규칙대로 기본으로 접고 버튼으로 열게 해야 한다(SHALL). 패널 안의 설정 항목은 키보드만으로 조작할 수 있어야 하고, 각 항목에는 눈에 보이는 이름표가 있어야 한다(MUST).

#### Scenario: 휴대폰 폭에서 설정 열기
- **WHEN** 폭 390px 화면에서 번역 화면을 열고 설정 버튼을 누른다
- **THEN** 패널이 작업 영역 위에 겹쳐 열리고 포커스가 패널 안 첫 조작 요소로 이동한다

#### Scenario: 이름표
- **WHEN** 설정 패널의 "자동 번역" 스위치에 포커스를 둔다
- **THEN** 스크린리더가 "자동 번역"이라는 이름과 켜짐·꺼짐 상태를 읽을 수 있다
