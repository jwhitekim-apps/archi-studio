# 디자인 토큰 대응표

벨루와 폴리오의 CSS 값을 Archi Studio 통합 토큰에 어떻게 대응시켰는지 기록한다. 기준은 `openspec/changes/archi-studio-scaffold/design.md` 결정 4, 5다.

- 벨루 출처: `veloo.2joon.com/web/src/shared/styles/index.css`, `web/tailwind.config.js`
- 폴리오 출처: `zotero-folio/web/src/app.css`
- 규칙: 구조(토큰 이름, 간격, 모서리, 치수)는 벨루, 다크 도입 방식은 폴리오, 포인트 색은 벨루 녹색(`#12876a`, 확정).
- 표기: "새로 정함"은 어느 쪽에도 없는 값이다. 대비 수치는 WCAG 상대 휘도로 계산한 값이다.

## 확인하지 못한 것

- 벨루 CSS 파일 140행 이후의 레거시 별칭(`--c-*` 등)은 이번 표에서 다루지 않았다. 새 앱에서는 가져오지 않는다.
- 폴리오 간격 값의 빈도 집계는 하드코딩이 너무 흩어져 있어 표로 만들지 못했다.
- 다크 값은 대비만 계산했고 화면에서 본 것은 아니다. 셸이 만들어지면 눈으로 다시 확인한다.
