# 예비 녹화 영상

인터넷이 막히면 영상을 틀고, 학교 LLM만 막히면 미리 만든 결과 화면으로 대체한다. 녹화는 기능 동결(11/21) 이후 실제 공개 주소에서 한다.

## 컷 목록 (대본 장면과 일대일)

| 파일 | 대본 장면 | 내용 | 길이 |
|---|---|---|---|
| `demo-s1.mp4` | 장면 1 흩어진 모습 | 벨루, 폴리오, 비서 캡처 3장 | 1분 |
| `demo-s2.mp4` | 장면 2 통합된 한 흐름 | 로그인 → 서재 → 논문 허브 → 분석 → 번역 → 메모 → 브리핑 | 2분 (AI 대기 구간은 잘라 낸다) |
| `demo-s3.mp4` | 장면 3 통합의 근거 | 메뉴 이동, 설정의 AI 항목, 주소창 | 1분 30초 |

## 녹화 방법

- 도구: OBS Studio(무료 화면 녹화 프로그램). 음성 없이 녹화하고 설명은 발표자가 직접 한다.
- 해상도 1920x1080, 30fps, MP4(H.264).
- 전체를 한 번에 녹화한 뒤 장면 경계에서 자른다. 예: `ffmpeg -i full.mp4 -ss 00:00:00 -to 00:01:00 -c copy demo-s1.mp4`.

## 보관과 점검

- 보관 위치 두 곳: 발표 노트북 로컬 디스크 `~/demo-video/`, USB 메모리 `demo-video/`.
- 두 곳이 같은지 확인: `sha256sum ~/demo-video/*.mp4 /media/<USB>/demo-video/*.mp4`.
- 발표 전날 각 파일을 끝까지 재생한다.

| 파일 | 크기 | 재생 시간 | sha256 일치 | 끝까지 재생 |

| demo-s2.mp4 | | | | |
